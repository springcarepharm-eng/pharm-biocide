# 살생물제품 판매가능 여부 조회 (약국용)

약국에서 취급하는 살충제·살균제·모기약 등의 **승인번호(또는 신고번호)나 제품명**을 입력하면,
2026년 7월 이후 **판매·유통 가능 여부**를 바로 확인해 주는 조회 도구입니다.

## 무엇을 알려주나요?

입력한 제품이 아래 4가지 상태 중 무엇인지 판정합니다.

- ✅ **승인 완료** — 판매 가능 (승인 유효기간까지)
- 🟡 **승인경과기간 적용** — 판매 가능하나 **2026.12.31까지** (심사결과에 따라 변동 가능)
- 🔵 **물질승인 유예기간 중** — 판매 가능 (유예기간 내)
- ⛔ **경과기간 종료** — **판매·유통 금지**

한 제품에 번호가 2개(예: `3219-0029 / 2219-0752`)여도 둘 중 아무거나 입력하면 찾아지고,
하나의 신고번호에 판매가능/불가 제품이 섞여 있으면 경고를 표시합니다.

## 데이터 출처

환경부 **초록누리(생활화학제품·살생물제 승인정보 공개시스템)** 가 공개한 엑셀 목록 5종
(살충제·살균제·살조제·살서제·기피제)을 통합했습니다.

- 목록 기준일: **2026년 7월 22일** (작성기준일 2026.6.26)
- 총 6,445건
- 초록누리: https://ecolife.mcee.go.kr/ecolife/main

## 사용 방법

`index.html` 파일 하나로 동작합니다. 별도 설치·서버 없이 브라우저에서 바로 열립니다.
웹 배포는 함께 제공된 **배포_가이드** 문서를 참고하세요.
